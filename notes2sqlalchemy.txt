HOW TO USE RELATIONSHIP AND back_populates:
     back populates help to connect in a continuous loop like user-post then pot-user

    Basic breakdown:

user       = relationship( "User" , back_populates="posts")
 ↑                  ↑                      ↑
Variable      Connected model      Variable name in User

Syntax:
    class User():
    posts = relationship("post, back_populates = "user)

    class Post:
    user = relationship("User", back_populates="posts")

tip:
->back_populates = "What's the relationship variable called on the other model?"
