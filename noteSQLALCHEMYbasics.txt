                                    SQLALCHEMY BASICS TO KNOW


ORM:
    ORM stands for object relational model
    It lets us work with Python objects instead of writing SQL for everything.

Core:
    SQLAlchemy Core is closer to SQL.

in short:
ORM  → Work with Python objects
Core → Work with SQL expressions

Connection pooling:
